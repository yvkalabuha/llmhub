### Проверено, всё в порядке
- **Create — один POST.** SDK нет. У `httpx.AsyncClient` повторов нет: `retries=0` по умолчанию, `follow_redirects=False`, `trust_env=False`. После отправки `ReadTimeout`, `WriteTimeout`, 5xx и 3xx дают `outcome_unknown=True` (`runpod_api.py:304-319`, `runpod.py:157-160`). Таймаут `GuardedAdapter` на create тоже даёт unknown (`guarded.py:244`). `create_unknown_max_retries == 0` закреплено валидатором. Второго POST нет ни в `provisioner` (`unknown_retries_exhausted`), ни в `recovery.py:131`. Тесты: новый `test_create_single_post_on_read_timeout_no_hidden_retry`, существующие `test_one_post_on_timeout_outcome_unknown` и F1-тесты ядра.
- **Пре-проверки** (`runpod.py:248-276`): метка, digest, `proxy`, разрешённый GPU, цена ≤ min(pool 0,30, ceiling ≤ 0,50). `max_live_pods` считает все `llmhub-*`, кроме TERMINATED (EXITED тоже). Сбой списка → отказ без POST. Повтор create разрешён только после определённого отказа или хоста из чёрного списка (в пределах `create_max_attempts = 2`).
- **Цена.** Потолок сравнивается с `costPerHr` — это цена до скидок, `adjustedCostPerHr` ≤ неё, так что консервативно. После create при превышении потолка или `costPerHr = None` под удаляется.
- **Тело create против реального `PodCreateInput`** (`test_create_body_money_fields_against_real_schema`): все поля есть в схеме. `volumeInGb: 0` (по умолчанию у RunPod было бы **20**), `cloudType: COMMUNITY` (по умолчанию SECURE), `interruptible: false`, `gpuCount: 1`. 3090 и CUDA 12.8/12.9 входят в enum. Полей `networkVolumeId`, `templateId`, `containerRegistryAuthId`, `globalNetworking`, `locked` нет. Диск 40 ГБ.
- **Destroy** — `DELETE /pods/{id}` (terminate), `/stop` не вызывается (`test_delete_targets_pod_terminate_not_stop`). `vol:` и `tpl:` отвергаются без HTTP. Ноль подтверждается через `list_owned` с `list_staleness_s`. Kill и reaper ниже по стеку проверяют HMAC (`reaper/core.py:278`).
- **Сторож** (если починить S1): удаляет только поды, которых не было в «до», с меткой строго по regex и не TERMINATED (`test_candidates_never_foreign_or_preexisting`). Чужой под без нашей метки он не удалит никогда.
- **Ключи.** Сервер: `0400 64100:0`; ключ монтируется `:ro` только в api и reaper (`@include-if-secret`, `check_s6k`), в env лежит только путь, `LLMHUB_RUNPOD_API_KEY` отвергается. Рабочая станция: 0600/0400, без симлинков. Ключ передаётся только в `Bearer`, в `str(err)` его нет, логгер `httpx` на WARNING.
- **Env пода** (виден любому ключу аккаунта через `GET /pods` и хосту Community): `LLMHUB_API_KEY` пода, `LLMHUB_WEIGHTS_TOKEN` (exp ≤ `created_at + 1800`, отзыв 403 после LOADING) и, только если задан `hf_token_env`, HF-токен. В шаблоне t372 HF-токена нет. Ключ RunPod и секреты контроллера в поды не попадают. Приемлемо.
- **Allowlist libgnutls FIPS — принят.** Это публичные тестовые векторы `crypto-selftests` в базовом образе Ubuntu 24.04. Условие: исправить REV-S6 (точное имя файла и, по возможности, только слои базового образа; строка `allowed: …` в отчёте). До push в P0 это не блокер.
- **`publish-infer.sh`**: токен через `--password-stdin` из файла 0600, временный `DOCKER_CONFIG`, logout в trap. Push отказывает, если id образа изменился после скана или скан не `clean`. Пакет GHCR публичный, pull по digest.
