## Цель
Быстрый старт GPU (цель этапа 4: медиана ≤ 5 мин) за счёт загрузки весов с нашего сервера с запасным путём через HF. Реализация и тесты без реальной сети и без установки на сервер (установка — T-371).
## Критерии приёмки
- [x] `weights.sources: [self_hosted, hf]` (R2 — опция, не реализуется); манифест с sha256; проверка контрольной суммы; докачка Range; переход к следующему источнику при ошибке **и** при скорости < `min_speed_mb_s` после 30 с — отдельные тесты на фейковых HTTP-источниках.
- [x] Сервер весов (`deploy/nginx-weights.conf` + выдача токенов): отдельный read-only HTTPS endpoint только для каталога GGUF; токен одноразовый, на инстанс, привязан к `op_id`, живёт до READY или таймаута LOADING_MODEL, затем отозван; `limit_rate`; ≤ 2 одновременных загрузок; VPN и локальные llama-server не затрагиваются. Тесты токенов: повтор, истёкший, чужой op_id.
- [x] Образ `llmhub-infer` (`infer-image/Dockerfile`): llama.cpp server-cuda (CUDA 12.8) собран внутрь, TLS-прокси + проверка ключа API, загрузчик весов; **веса не запекаются**. Сборка на платных ресурсах не выполняется; проверяются юнит-тесты загрузчика и lint Dockerfile.
- [x] Режимы TLS `direct` (pin отпечатка) и `proxy` (ключ на инстанс) отражены в конфиге и спецификации инстанса; какой доступен — проверка этапа 4 (T-372).
- [x] Ничего не открывается на сервере и не публикуется; pytest, ruff, pyright чисто; ревью ≤ 3 раундов.
