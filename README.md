# llmhub

> TL;DR: Служба-диспетчер LLM: один OpenAI-совместимый API для локальных llama-server и арендуемой по требованию облачной GPU (RunPod/dstack/Vast через адаптеры). Минимизирует совокупную стоимость, бюджет $50/мес, облако всегда уничтожается после работы. Статус: каркас (ADR-0138), реализация на Mock — T-368…T-371.

## Зачем
Постоянный сервер без GPU держит control plane и локальные модели; тяжёлые задачи уходят на облачную 3090 только когда это выгодно и разрешено политикой. Клиенты — VoiceBot, gameDev (C#/.NET) и другие.

## Как подключить клиента
1. Администратор заводит клиента (ключ хранится хешем): `allowed_models`, `max_priority`, `data_class` (по умолчанию `private` — только локально; облако — явный `cloud_allowed`).
2. Клиент задаёт окружение:
   ```
   OPENAI_BASE_URL=http://10.8.0.1:8095/v1
   OPENAI_API_KEY=<клиентский ключ llmhub>
   ```
3. Обычные запросы `/v1/chat/completions` (в т.ч. `stream`) работают как у OpenAI. Синхронное ожидание ≤ 8 мин, затем `503` + `Retry-After` + `task_id`; таймаут клиента должен быть больше (openai-python — 600 с). Долгие задачи и явные GPU-сеансы — `/v1/tasks`, `/v1/leases` (`docs/integration.md`, черновик).

## Разработка
